# Product interface

- Build a compact professional desktop tool. Use concise, functional labels.
- Do not add promotional copy, slogans, taglines, decorative text, reassurance badges, or redundant descriptions of the app.
- Keep instructions only where needed to resolve an action's ambiguity or prevent a mistake. Put general usage instructions in Help, and secondary explanations in tooltips.
- Preserve readable controls, clear save/error states, and warnings about file operations while reducing wasted space.
